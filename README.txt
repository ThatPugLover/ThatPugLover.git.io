Abuzz Solutions website concept
================================
Open index.html in any browser to view the site. It is a single self-contained file
(styles, scripts, map data, logos and case study photos are all embedded), so no
internet connection or build step is needed.

Pages (hash-routed): #home, #about, #services, #case-studies (+ five client pages),
#team, #blog, #support, #contact.

Contact form: the Send button opens the visitor's email app with a message addressed to
customercare@abuzz.com.au. To send automatically, connect a form service or backend.

Placeholders still to fill: Team profiles, Blog posts, social links.
